Einstellungen auf einen anderen PC übertragen:

Game Booster

Pausiert Hintergrunddienste und Apps, solange du spielst – danach wird alles wiederhergestellt.

Game Boost ist aus

Startet den GameBoost-Energieplan, stoppt Dienste, beendet Apps und leert den Standby-RAM.

⚡ Auto-Boost

Startet den Boost automatisch, sobald ein Spiel aus der Bibliothek läuft – auch wenn du es über Steam, Epic oder eine Desktop-Verknüpfung startest. Endet mit dem Spiel.

Spiele-Bibliothek

Für jedes Spiel setzt GameBoost hohe CPU-Priorität und die Hochleistungs-GPU. Beim Start über GameBoost läuft der Boost automatisch, bis das Spiel beendet ist.
